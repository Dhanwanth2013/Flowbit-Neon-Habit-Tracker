### **Next-Gen Offline Habit Tracker — Neon UI, Zero Cloud, Pure Progress**

## ⚡ Overview

**Flowbit Neon** is not just a habit tracker — it’s your **daily command center**, built with a stunning neon UI and designed for people who want privacy-focused productivity with style.

This is a **single-file, offline-first, zero-dependency productivity tool**, bringing together habit tracking, mood logs, analytics, heatmaps, and gamification — all wrapped in a futuristic, glow-infused interface.

No accounts.
No servers.
No limits.
Just **you and your growth**.

---

## ✨ Core Highlights

### 🔥 **Neon-Powered Habit Tracking**

* Create, manage, and customize habits with ease
* Add emoji icons, subtasks, and custom goals
* Daily check-ins with mood logging and notes
* Automatic streaks + progress calculations
* Editable history with a sleek modal

### 🌈 **Beautiful UI / UX**

* Cyberpunk neon gradients ⚡
* Animated progress rings
* Smooth transitions & micro-interactions
* Dark / Light mode toggle
* Four accent colors:
  🔵 Cyan | 🟣 Purple | 💗 Pink | 🟢 Green
* Fully responsive — works on phone and desktop flawlessly

### 🔍 **Advanced Analytics**

* **90-day heatmap**
* **Habit performance charts**
* **Mood graphs & trendlines**
* Weekly & monthly summaries
* Automatic habit performance scoring
* Streak insight breakdown

### 🤖 **AI-Like Smart Suggestions**

FlowHabit Neon includes a lightweight, local, rule-based assistant that detects:

* drop in streaks
* mood dips
* irregular completion patterns
* sudden spikes in consistency

…and gives **personalized habit improvement tips**, with *zero* data leaving your device.

### 🧩 **Power Tools**

* Import / Export your data (single JSON file)
* Undo system (Ctrl + Z)
* Browser notifications for reminders
* Offline forever — works even without internet
* Emoji-powered habit icons
* Touch gestures on mobile (swipe heatmap)

## 🚀 Getting Started

1. Download `flowbit_neon.html`
2. Open it in any browser
3. Start tracking instantly — no setup
4. Customize theme + habits
5. Enjoy the clean offline workflow

For backup:
**Settings → Export Data → JSON**
You can later **Import** it back anytime.
